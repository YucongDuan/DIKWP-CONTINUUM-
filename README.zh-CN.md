# DIKWP-CONTINUUM²

Created by Yucong Duan (段玉聪).

跨基质生命连续性、身份保真与开放式长生系统。

本项目不是“意识上传已经成功”的宣称，也不提供个人医疗诊断。它把长生意图拆分为可审计的连续性问题：生物可生存、神经完整、因果连续、记忆、人格与价值、能动目的、具身、关系、法律身份、数字韧性、可恢复性以及现象体验证据。

## 核心原则

1. DIKWP 是网状语义系统，不是 D→I→K→W→P 的层级流水线；原型覆盖 25 类 DIKWP×DIKWP 有向变换。
2. 任何“本人延续”主张必须同时接受多种身份理论检验。
3. 破坏性扫描最多生成数字后继或档案，不能自动等同于本人继续存在。
4. 优先采用可逆、重叠、可撤销、有人类复核的干预。
5. 现象意识连续性永久保留不可消除的认识论残差。

## 运行

```bash
cd DIKWP_CONTINUUM2_MVP
PYTHONPATH=src python -m dikwp_continuum2 --trials 1500 --seed 7152026
python -m unittest discover -s tests -v
```

然后打开 `outputs/dashboard.html`。

## 目录

- `config/`：身份假说、策略、技术里程碑
- `examples/`：合成示范档案，不含真实健康数据
- `src/`：模拟、门控、身份谱系、DIKWP网状语义和报告生成
- `schemas/`：Purpose Contract 与连续性档案 JSON Schema
- `tests/`：自动测试
- `outputs/`：运行结果、仪表盘、预测合同、审计账本

## 安全边界

- 所有医疗相关内容仅用于研究架构与决策流程设计；现实实施必须由合格临床机构、伦理委员会和监管框架负责。
- 禁止未经批准的干细胞、外泌体、基因编辑、全身重编程或破坏性神经操作。
- 原型概率和年份为合成种子先验，不是寿命预言或厂商承诺。
